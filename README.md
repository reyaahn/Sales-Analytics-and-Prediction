# WeIntern – Data Science Internship Project

## Project Overview

This repository contains my Week 2 Data Science internship tasks at WeIntern.

The project focuses on understanding and analysing an E-commerce Sales Dataset using Python, Pandas, NumPy, Matplotlib, Seaborn and Machine Learning.

## Dataset Information

- Dataset: E-commerce Sales Analytics
- Total Records: 5,000
- Total Columns: 12
- Target Variable: Revenue

## Tasks Completed

### Task 1 – Data Cleaning
- Dataset loading and inspection
- Missing value checking
- Duplicate record handling
- Data type conversion
- Outlier detection using IQR
- Categorical data encoding
- Exporting cleaned data

### Task 2 – Exploratory Data Analysis (EDA)
- Descriptive statistics
- Revenue distribution
- Product category analysis
- Regional sales analysis
- Monthly revenue trends
- Payment method analysis
- Correlation heatmap
- Business insights

### Task 3 – Sales Prediction
- Feature engineering
- Train-test splitting
- Linear Regression
- Random Forest Regression
- Model evaluation using MAE, RMSE and R²
- Actual vs Predicted visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Structure

- `data/` – Original and cleaned datasets
- `notebooks/` – Three task notebooks
- `reports/` – Model results and reports

## Learning Outcomes

Through this project, I gained practical experience in data cleaning, data visualization, exploratory data analysis and machine learning model development.
